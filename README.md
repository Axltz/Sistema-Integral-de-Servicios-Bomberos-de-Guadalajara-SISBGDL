# Sistema de Gestión de Personal y Operativos - Bomberos Guadalajara

Sistema modular desarrollado en Node.js con TypeScript para la gestión de perfiles, cargos operativos y selección equitativa de personal.

## Arquitectura
- **Backend:** Node.js, Express, TypeScript.
- **Patrón:** Clean Architecture (Controller-Service-Repository).

## Estructura de Scripts
- `npm run dev`: Ejecuta el servidor de desarrollo con Hot Reload.
- `npm run build`: Compila el código TypeScript a JavaScript en `/dist`.
- `npm run start`: Inicia la versión de producción desde `/dist`.
